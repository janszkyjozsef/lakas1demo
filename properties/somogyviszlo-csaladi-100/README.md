# Somogyviszlói otthon — OTTHONÍV

A bemutató az eredeti hirdetésből, rendezett forrásfotókból, fotófilmből, saját szemléltető modellből és modellfilmből, valamint három külön jelölt AI-filmből áll. A teljes ingatlanmappa és a shared mappa együtt használható kiszolgálóról. A fotók digitális rendrakást kaptak; a modell nem felmérés.
