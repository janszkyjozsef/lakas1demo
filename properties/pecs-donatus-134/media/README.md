# Donátus — építészeti tervlátványok

A négy kép ugyanahhoz a tervezett ikerházas épületegyütteshez tartozik. Nem jelenlegi állapotfotók. A jelölések digitális eltávolítása mellett finom tónus- és textúrarészletek módosulhattak. A bemutatóban külön szerepelnek a források és a tervmodell korlátai.
