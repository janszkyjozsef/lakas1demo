# Donátus — filmek

A forrásfilm külső építészeti tervlátványokból szerkesztett bemutató. Nem helyszíni videó. A térmodellből készült film arányos, nem felmérésen alapuló szemléltetés; a választható bútorzat berendezési ötlet.

A filmek és a zene közzététele nem jelent szabad újrafelhasználási licencet.
