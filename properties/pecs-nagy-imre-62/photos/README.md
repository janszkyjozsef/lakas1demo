# Pécs, Nagy Imre út – retusált hirdetési fotók

A 2026. október 22-i Ulrika Niesz-hirdetés saját képsorából készült, MI-vel retusált változatok. A finom textúrák és tükröződések módosulhattak. A mosógép ajtaja digitálisan becsukva. A bemutató külön elérhetővé teszi az eredeti forrásképeket.

A 3D-bemutató közzétételének előkészítése folyamatban.
