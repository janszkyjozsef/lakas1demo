# Egyetemvárosi fény — 47 m²-es lakásbemutató

[A lakás külön bemutatóoldala](../../egyetemvaros.html)

A korábbi egyetemvárosi lakás bemutatója digitálisan rendezett képekkel, filmekkel és forgatható térmodellel. A képi módosítások és a modell becsült részletei szemléltető jellegűek; a 3D nem hiteles felmérés.
